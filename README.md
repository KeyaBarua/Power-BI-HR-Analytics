# HR Analytics in Power BI

## 📊 Project Overview

This project explores employee data using **Power BI** to understand workforce demographics, employee performance, attrition patterns, and other key HR metrics.

The project was completed as part of the **HR Analytics in Power BI case study on DataCamp** and provided hands-on experience in transforming HR data into meaningful business insights through interactive dashboards using datasets from a fictitious company called **Atlas Labs**.

The primary objective was to demonstrate how HR teams can use data analytics to better understand their workforce and support data-driven decision-making.

---

## 🎯 Business Objectives

The analysis aims to answer several key HR questions:

* What is the overall size and composition of the workforce?
* What are the main demographic characteristics of employees?
* How does employee performance vary across the organisation?
* What factors may be associated with employee attrition?
* Which employee groups or departments experience higher turnover?
* How can HR teams use workforce data to improve employee retention and workforce planning?

## 🔄 Data Preparation

The dataset was prepared and transformed using **Power Query** before being used for analysis.

The data preparation process included:

* Reviewing data types and column structures
* Cleaning and transforming employee data
* Preparing fields for analysis
* Creating appropriate relationships between tables
* Ensuring the data model could support the required HR metrics

---

## 🧩 Data Modelling

A structured Power BI data model was used to connect the relevant HR data.

Relationships between the tables enabled analysis across different areas of the organisation, including:

* Employee demographics
* Performance
* Job roles
* Departments
* Attrition

This allowed different dimensions of employee data to be analysed together within the dashboard.

---

## 📐 DAX & Calculated Metrics

DAX measures and calculated fields were used to generate key HR metrics and support the dashboard analysis.

Examples include:

* Total Employees
* Active Employees
* Inactive Employees
* Attrition Rate
* Average Age
* Average Salary
* Average Performance Rating

These measures allow the dashboard to respond dynamically to filters and slicers.

---

## 📈 Dashboard Analysis

### Employee Overview

The dashboard provides an overview of the organisation's workforce, including employee numbers and key demographic characteristics.

The analysis allows HR stakeholders to explore workforce composition across different employee groups.

### Demographics

Employee demographic information was analysed to better understand the structure of the workforce.

This includes analysis by factors such as:

* Age
* Gender
* Marital status
* Ethnicity

### Performance

Employee performance data was analysed to identify patterns in performance ratings and understand how performance varies across different groups within the organisation.

### Attrition

Attrition analysis was used to investigate employee turnover and identify areas where employee departures may be concentrated.

The dashboard enables users to explore attrition across dimensions such as:

* Department
* Job role
* Age group
* Employee characteristics
* Other workforce factors

## 🔍 Key Insights

The dashboard demonstrates how HR data can be used to identify workforce trends and potential areas of concern.

Key areas explored include:

* Workforce demographic distribution
* Employee performance patterns

These insights can help HR teams identify areas requiring further investigation and support evidence-based workforce decisions.
